# Feliz 80 Cumpleaños, Mario 🌻

A birthday tribute website for Mario's 80th birthday, published via GitHub Pages.

## What's on the page

- Full-screen hero photo with animated title
- Personal birthday message
- Photo gallery with lightbox (21 photos)
- Video tribute (`video1.mp4`)
- Milestones timeline
- Birthday wishes
- Poem: *Auschwitz-Birkenau-Treblinca-Dachau* — displayed in two-column layout with prose stanzas
- Background music player (Glenn Miller, Moonlight Serenade — public domain)
- Floating petals animation

## Fonts

- **Jost** (Google Fonts) — geometric sans-serif, close to Futura — used for body text
- **Cormorant Garamond** — elegant serif for headings and poem body
- **Cinzel** — decorative caps for section labels

## Files

| File | Description |
|------|-------------|
| `index.html` | Main page (single file, no build step) |
| `birthday-photo.jpeg` | Hero background image |
| `p1.jpeg` – `p21.jpeg` | Gallery photos |
| `video1.mp4` | Video tribute |
| `Auschwitz.docx` | Source document for the poem |

## Deploying to GitHub Pages

1. Push this folder to a GitHub repository
2. Go to **Settings → Pages**
3. Set source to `main` branch, root folder (`/`)
4. The site will be live at `https://<username>.github.io/<repo-name>/`
